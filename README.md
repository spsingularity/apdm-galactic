# apdm-galactic

**The Galactic Face of the Entropy Clock: MOND as a Rate-Branch Acceleration Scale a0 proportional to H(z)**

Paper VIII of the USC program (galactic / MOND): the density branch a0~sqrt(rho_DE) is excluded at 17sigma by high-z kinematics (pipeline-conditional); the surviving rate branch gives a0 propto H(z); a partial worldline derivation yields a cot-kernel where the 4pi appears, coefficient still open.

Part of the USC research program (SEDE / ECCG / APDM unification). See the program map for how
this paper relates to the others. Companion papers are cited by Zenodo DOI (assigned on release).
